# Sustainability Tracker 🌱

A full-stack web application to track and encourage sustainable lifestyle habits.

---

## 🚀 Features

- ✅ User Registration & Login (with email notifications)
- 📬 Login/Signup Email Alerts using NodeMailer
- 📝 Personal Sustainability Actions Tracker
- 📊 Carbon Footprint Estimator
- 🏆 Community Leaderboard
- 🔒 JWT-based Authentication
- 📦 PostgreSQL Integration

## ⚙️ Getting Started

- npm install
- npm start

-> open another terminal at root directory
- node server.js


🛠️ Tech Stack
Frontend: React, CSS

Backend: Node.js, Express

Database: PostgreSQL

Mailing: NodeMailer

Auth: JWT
